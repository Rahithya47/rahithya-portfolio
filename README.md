## About This Project

This website is my personal space on the web. It brings together information about my background, the projects I've worked on, my technical interests, and ways to contact me.

The project is built with React and Vite, with Tailwind CSS for styling.

- Personal introduction and education details

- Responsive layout for different screen sizes

## Run Locally

Make sure Node.js and npm are installed on your computer.

1. Clone this repository:

   ```bash
   git clone https://github.com/Rahithya47/rahithya-portfolio-v3.git
   ```

2. Open the project directory:

   ```bash
   cd rahithya-portfolio-v3
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal, usually `http://localhost:5173/`.

## Build for Production

To create a production build, run:

```bash
npm run build
```

Vite generates the production files in the `dist` directory.
